# SushiCoacoara — Calendário Editorial

Landing page estática para apresentar à Dani o calendário editorial da SushiCoacoara, seguindo a identidade visual do relatório de referência: fundo azul-marinho quase preto, cartões escuros, acentos violeta e verde menta, tipografia editorial e hierarquia executiva.

## Desenvolvimento

```bash
npm install
npm run dev
```

O Preview local usa a porta 3000.

## Build para Cloudflare Pages

- **Build command:** `npm run build`
- **Build output directory:** `dist`
- **Framework preset:** Vite

A página é estática e não depende de servidor ou banco de dados.
